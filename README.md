# E-Commerce Sales Analysis - Excel

## Project Overview
This project analyzes e-commerce sales data using Microsoft Excel to understand sales, profit, city-wise performance, category-wise sales, and product-wise quantity sold.

## Tools Used
- Microsoft Excel

## Key Results
- Total Sales: ₹5,04,500
- Total Profit: ₹85,500
- Total Quantity Sold: 69
- Total Orders: 20
- Highest Sales City: Mumbai (₹2,07,000)
- Electronics Sales: ₹4,25,000
- Accessories Sales: ₹79,500
